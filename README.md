# Warm Hug

A procedural 768 x 768 PNG illustration generated with Node.js 22 and its standard library.

Run from the repository root:

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The image is written to `out/entry.png`.
